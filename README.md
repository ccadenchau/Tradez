Simple and easy to use trading extension. Provides additional data through my [personal economy api](https://rolimons.cadenchau.com)

**Features**
- Item value and detail labels to inventory cards (value, best seller, number of sellers)
- RAP history charts on item cards
- Projected item warnings
- Offer balance summaries
- Automatic data refresh from API every five seconds (no tab refresh needed for new data to show)
- Instant image loading for limiteds
